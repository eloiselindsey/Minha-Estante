Sobre o MinhaEstante

O MinhaEstante foi criado para que leitores organizem suas histórias favoritas e acompanhem o próprio ritmo de leitura, sem se perder entre os títulos que já terminaram e os que ainda desejam conhecer.

Projeto Integrador

Este é um projeto acadêmico do 2º ano do Ensino Médio Técnico em Informática que reúne Desenvolvimento de Websites, Programação Orientada a Objetos e Banco de Dados. A interface foi feita com HTML, CSS e JavaScript; a API utiliza Python e Flask; o armazenamento local utiliza SQLite.

O sistema registra livros e leituras, atualiza informações, calcula progresso, salva avaliações e comentários. O conteúdo continua no banco após fechar o programa.

Limitação importante: esta versão é uma demonstração local com um único perfil. Não há login, contas privadas nem proteção de acesso multiusuário. Não publique a API como serviço público.
